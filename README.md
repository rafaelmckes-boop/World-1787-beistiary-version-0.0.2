#  Bestiary of World 1787

An interactive medieval-style bestiary containing characters, creatures, anomalies, organizations, and other entities from **World 1787**.

The website is designed to feel like an old medieval manuscript while functioning as an expandable database for the world and its lore.

##  Features

- Medieval parchment-inspired design
- Multiple bestiary categories
- Character and creature entries
- Character portraits
- Detailed lore pages
- Character statistics
- 10-level danger meter
- Multiple character forms/versions
- Different images and danger ratings for each form
- Search bar
- Background music
- Sound effects
- Medieval fonts
- Custom quill cursor
- Interactive world map
- Animated text and page effects

##  Categories

The bestiary is divided into several major categories:

### Humans

Contains human or human-like characters.

Current subcategories include:

- Survivors
- Misc
- Organizations
- Agents

### Anomalies

Entities, objects, or beings that do not follow the normal rules of World 1787 (People not originating from World 1787).

### Insolence

Creatures and entities connected to the Insolent Realm. The main antagonists

### Others

Entries that do not fit into the other major categories.

##  Character Pages

Character pages contain:

- Name
- Portrait
- Lore
- Origin
- Health
- Defense
- Attack
- Speed
- Rarity
- Abilities and attacks
- Danger level

Some characters also have multiple versions.

Arrows beside their portrait can be used to switch between these versions. Different forms may have their own portrait and danger level.

##  World Map

The bestiary can also contain an interactive map of World 1787. (Currently a litle outdated and broken)

Regions can be connected to characters, creatures, organizations, anomalies, and other lore found within that area.


##  Style

Most of the website's appearance is controlled through style.css


The main medieval title font is **Uncial Antiqua**, with **Garamond** used for much of the normal text.

##  Audio

The website supports background music and interface sound effects.

Audio can be muted using the sound button on the main page.
